# Park Tennis Brand Index rubric demo

Park Tennis uses an editorial rubric to research independent tennis brands for public-court players. This demo uses two fictional brands and synthetic evidence to show how a score informs an editor's decision to include a brand, ask for more evidence, or pass.

**[Try the demo](https://park-tennis.github.io/brand-index-rubric-demo/)**

Start with Bench Pocket Tennis. Then open Last Light Rally Co. and compare its initial packet with the follow-up. The evidence table shows what supports each rating and what remains uncertain. Open **How the score is calculated** to see the weighted arithmetic.

To run it offline, download or clone this repository and open `index.html` in a browser. Everything runs in that file.
